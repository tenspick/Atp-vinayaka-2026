# ANANTHAMPALLI VILLAGE VINAYAKA CHAVITHI 2026 (AVVC 2026)

Full-stack production-grade website and local admin management system for **ANANTHAMPALLI VILLAGE VINAYAKA CHAVITHI 2026**.

---

## 🛠️ Technology Stack

- **Backend**: Node.js + Express.js static web server
- **Frontend**: Semantic HTML5, CSS3 (Vanilla + CSS Variables + Festive Aesthetics), Vanilla JavaScript (ES6+)

---

## 🚀 How to Run Locally

### 1. Prerequisites
- Node.js (v16+ or v18+ recommended)
- npm (Node Package Manager)

### 2. Installation & Run Steps

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Start Local Express Server**:
   ```bash
   npm start
   ```

3. **Access Application in Browser**:
   - **Public Website**: [http://localhost:3000](http://localhost:3000)
